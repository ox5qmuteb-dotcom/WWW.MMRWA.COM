# Development Environment Setup

## Prerequisites

- Git
- A modern code editor with EditorConfig support

## Setup

1. Clone the repository.
2. Create a local branch from `main`.
3. Copy environment templates as needed:
   - `.env.example` -> `.env`
   - `config/app.config.example.yml` -> `config/app.config.local.yml`

## Workflow

1. Implement focused changes.
2. Validate locally.
3. Open a pull request using the template.
